01

Design Principles

間
Ma · Space

Negative space as intentional design. The interface breathes. Never overcrowd a surface.

清
Clarity

Swiss typographic hierarchy. Information density is controlled, not avoided.

流
Flow

Every interaction is animated. Entry, exit, press — all have organic motion and haptic feedback.

真
Truth

Real data. No blurred amounts, no ellipsis on numbers. Financial clarity is non-negotiable.

Pink (#FF0048) Usage Rule

Pink is reserved for: logo, FAB, balance card bg, form focus rings, active dock indicators, and action CTAs. Text on pink surfaces always uses #450010 — never pure black or white. Never use pink for errors or destructive states — use amber (#FB8C00) for warnings.

⚠ Never use spring for AnimatePresence content transitions

Content enter/exit (cards, screens mounting) must use type: 'timing' with 190–300ms. Spring on AnimatePresence causes jarring bounce. Reserve spring exclusively for interactive press feedback (scale transforms).

08

Currency Formatting

USD Amount
$12.00

Prefix "$". Always 2 decimal places. Small: 20–22px/600. Hero: 62px/300 on balance card.

ZiG Amount
ZiG 4,200

Prefix "ZiG ". Zero decimal places. Thousands separator via .toLocaleString().

Net Display
$15.50

Always shown as positive value. "Net ahead" overline label when net > 0. Hero card: 62px/300.
